# ChamaPro
O ChamaPro é um aplicativo mobile que propõe um sistema para solicitação e contratação de serviços de eletricistas, de forma online, interativa e acessível, conectando clientes a profissionais autônomos em um único ambiente digital. A proposta busca facilitar situações do cotidiano que exigem atendimento elétrico, permitindo encontrar, de forma rápida e confiável, um eletricista disponível para realizar o serviço necessário, sem depender apenas de indicações informais.
